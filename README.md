# TNT Physics

A Minecraft NeoForge mod that adds physics-like TNT explosions using falling blocks.

When TNT explodes, affected blocks are converted into falling block entities and launched outward, creating a more dynamic and realistic destruction effect.
Instead of blocks simply disappearing, they are physically scattered by the blast, making explosions feel more realistic and chaotic.

Built for Minecraft 1.21.1 using NeoForge.

# Instalation:
  1.Download: https://github.com/egsamuta-oss/tntphysics-mc/releases/tag/Realeases
  and click on tntphysics-1.0.0.jar file
  
  2.Move your .jar file to minecraft mods folder: 
    Windows : C:Users\YOUR_USERNAME\AppData\Roaming\.minecraft\mods
    Linux : \home\YOUR_USERNAME\.minecraft\mods
    MacOS : ~\Library\Application Support\.minecraft\mods
